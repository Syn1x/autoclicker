Autoclicker 1.5.3 adds a rainbow color cycle to the cursor's glowing click rings.

- Successive click rings cycle through the full RGB spectrum every six seconds.
- Each ring keeps its color while expanding and fading over 180 ms at the click point.
- Reuses cached color frames and the existing overlay pool and timer.
- Preserves click-through behavior, minimized visibility, and immediate cleanup when clicking stops or the app closes.

The indicator confirms input sent to Windows, not game registration. Use windowed or borderless mode if an exclusive-fullscreen game hides the overlay.

Choose **Check for updates → Confirm update → Restart to update**. Versions before 1.3.0 apply on close and need to be reopened manually. You can also download **autoclicker.exe** directly; it is still one portable file.
