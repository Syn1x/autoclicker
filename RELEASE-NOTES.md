Autoclicker 1.0.3 uses the Cypress Dynamics logo as its Windows application icon.

- The running window and taskbar use the logo.
- The executable, installer, and shortcuts share the same icon.
- Includes icon sizes from 16 to 256 pixels for standard and high-DPI displays.

The app is still named Autoclicker and retains its neutral dark interface. Keyboard controls, the stop timer, sound cues, and automatic updates work as before. Existing installations receive this update on their next check and apply it when the app closes. The saved keyboard binding is preserved.

Download autoclicker.exe, or extract the complete portable ZIP. Existing standalone EXE users need this download once to enable future automatic updates.

This release is unsigned; publisher code signing has not been configured.
