# Application icon

`cypress-dynamics.png` is the existing Cypress Dynamics logo, included at the owner's request for Autoclicker's Windows icon.

`autoclicker.ico` preserves the artwork and transparency in 16, 20, 24, 32, 40, 48, 64, 128, and 256 pixel frames. It is embedded in the executable and window and passed to Velopack for the installer and shortcuts.
