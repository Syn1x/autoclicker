# Application icon

`cypress-dynamics.png` is the existing Cypress Dynamics logo, included at the owner's request for Autoclicker's Windows icon.

`autoclicker.ico` preserves the artwork and transparency in 16, 20, 24, 32, 40, 48, 64, 128, and 256 pixel Windows DIB frames. It is embedded in the standalone executable and window, including the taskbar icon.
